# Tank Robot Development Project
戦車型ロボットを題材に、要求仕様、設計、実装、評価までを学ぶための開発プロジェクトです。

Tank_Robotそのものを販売することが目的ではなく、一人で、要求仕様 → 基本設計 → 詳細設計 → 実装 → システムテストまで一通り経験し、IoT／組込み製品開発に必要な知識を身につけられる教材を作ることが目的です。

ただし教材だからといって、おもちゃレベルに簡略化するのではなく、実際の市販製品で要求される安全性、セキュリティ、異常処理、更新、通信、ログ、保守などを意識した製品開発を経験できることも重要です。

今回のゴールは、量産筐体まで作って実際に販売可能な完成品を製造することではなく、量産製品を想定したシステム構成・ソフトウェア・安全・セキュリティを、評価環境上で実装して検証するところまでです。

つまり、市販製品そのものを作るのではなく、市販製品レベルのシステム開発を評価環境上で経験するという位置づけです。

本リポジトリでは、試作機の接続確認、要求仕様、ハードウェア構成、ファームウェア、評価結果などを整理して公開していきます。
## Project status
接続確認用試作を経て、現在は製品目的・製品目標およびシステム要求仕様を整理し、要求仕様を基にした評価環境・基本設計へ進む準備を進めています。

製品目的・製品目標から順次、本リポジトリへ公開していきます。
