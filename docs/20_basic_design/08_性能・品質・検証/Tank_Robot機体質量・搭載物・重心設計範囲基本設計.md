## 1. 基本方針

**位置付けと目的**

- **位置付け**：[「性能・品質・検証基本設計」](Tank_Robot性能・品質・検証基本設計.md)および懸案事項一覧 `BD-ISSUE-003`／`BD-EVAL-014`を補完する補足設計書
- **目的**：機体質量、利用者による追加搭載物、教材として定義する追加モジュール、および重心条件について、設計時に先に定める制約と、完成後に実測・評価して確定する値を分ける

システム全体の性能・品質・評価条件は引き続き性能・品質・検証基本設計に従い、評価確定待ち事項は懸案事項一覧で横断的に追跡する。本書は、上記の目的に示した範囲でこれらの文書を補完し、本書による補完前に`M_STD`、`M_MAX`、`PAYLOAD_MAX`、`CG_ENVELOPE`を一括して「完成後に測って確定する」とした分類を置き換える。

**対象文書**

- [`docs/20_basic_design/08_性能・品質・検証/Tank_Robot性能・品質・検証基本設計.md`](Tank_Robot性能・品質・検証基本設計.md) §4.3、§16.1
- [`docs/20_basic_design/03_機能別基本設計/00_懸案事項.md`](../03_機能別基本設計/00_懸案事項.md) `BD-ISSUE-003`、`BD-EVAL-014`

**本書と関連文書の適用範囲**

1. **本書が定める事項**：機体質量・追加搭載物・重心について、設計時に定める制約と、完成後に実測・評価して確定する値の区分。
2. **関連文書が引き続き定める事項**：本書が明示的に補完する事項、または文書間で共通の規則として確定する事項以外は、本書で挙げる関連する基本設計の担当範囲と変更責任を維持する。
3. **本書を優先する場合**：上記の事項について本書で基本設計として確定した記述と、当該事項への対応前の旧記述が競合する範囲に限る。対応経緯と、比較基準の版がある場合の識別情報は、末尾の「作成経緯」に示す。
4. **本書を優先しない事項**：詳細設計へ残す内部実装、および補完対象外の状態、機能の動作、安全、セキュリティ、外部との通信・連携規則などは、それぞれを担当する基本設計に従う。

**基本方針**

初期製品では次を採用する。

1. Tank_Robotは、製品として定義した標準構成で使用することを基本とする。
2. 利用者が任意の荷物、機器、バッテリー、カメラ、基板その他を追加して運搬・搭載する用途は、通常使用としてサポートしない。
3. 教材として正式に定義した追加センサ、追加基板、カメラ等は、個別に設計・評価した**承認済み追加モジュール構成**としてのみ許可できる。
4. 詳細設計は、完成後の実測値を待たずに守るべき暫定質量上限と重心安定条件を使用する。
5. 完成後は標準機体および承認済み追加モジュール構成の実測質量・重心を取得し、設計範囲内かつ走行、停止、傾斜、転倒、電源、熱、耐久の成立を確認する。
6. 実測・評価が設計範囲を満たさない場合は、評価結果を理由に設計限界を自動拡大せず、性能・品質・検証基本設計および関連事項を定める基本設計へ戻す。

## 2. 用語と識別子

| ID | 区分 | 意味 | 状態 |
| --- | --- | --- | --- |
| `M_DESIGN_MAX` | 設計限界 | 標準構成または承認済み追加モジュール構成について、詳細設計が超えてはならない総質量上限 | 基本設計確定 |
| `M_STD_MEASURED` | 実測値 | 完成した標準構成の実測総質量 | 評価確定待ち |
| `M_CONFIG_MEASURED[c]` | 実測値 | 承認済み追加モジュール構成`c`の実測総質量 | 当該構成評価時に確定 |
| `PAYLOAD_USER_MAX` | 利用限界 | 利用者が任意に追加してよい外部搭載物の質量 | 基本設計確定 |
| `CG_DESIGN_ENVELOPE` | 設計限界 | 標準構成・承認済み追加構成が満たすべき重心安定条件 | 基本設計確定 |
| `CG_STD_MEASURED` | 実測値 | 完成した標準構成の実測重心 | 評価確定待ち |
| `CG_CONFIG_MEASURED[c]` | 実測値 | 承認済み追加モジュール構成`c`の実測重心 | 当該構成評価時に確定 |

旧`M_STD`は`M_STD_MEASURED`へ、旧`PAYLOAD_MAX`は初期製品では`PAYLOAD_USER_MAX`へ読み替える。

旧`M_MAX`は「完成後に測って決める値」ではなく、本書の`M_DESIGN_MAX`と、最終評価後に成立が確認された個々の構成質量を区別して扱う。機械的に載せられる最大重量を製品保証値として新設しない。

## 3. 質量設計範囲

### 3.1 暫定総質量上限

初期製品の暫定設計上限を次とする。

```text
M_DESIGN_MAX = 4.0 kg
```

この4.0 kgは、完成機の推定重量を表す値ではなく、詳細設計が走行、停止、電源、熱、機構安定性を成立させるために守る**初期設計の質量上限**である。

標準構成には、少なくとも次を含む。

- シャーシ、左右DCモータ、キャタピラ、モータドライバ。
- 砲塔・砲身機構、サーボ×2。
- RA8M2制御基板および製品基板・配線。
- BLE、Wi-Fi、外付けFlash、RTCその他の標準電子部品。
- 標準バッテリー、電源回路、コネクタ、保護部品。
- 外装、固定具、配線保持部品、表示部、操作部。

詳細設計時の部品積上げ質量が4.0 kgを超える見込みとなった場合、詳細設計だけで上限を拡大しない。機構、電源、走行、停止、安全評価条件を含め性能・品質・検証基本設計へ戻して再判断する。

### 3.2 標準機体実測質量

`M_STD_MEASURED`は完成した標準構成を実測して確定する。

実測値は評価確定待ちであり、詳細設計開始時に推測で正式値を置かない。ただし、詳細設計では部品表から積上げ見積りを持ち、`M_DESIGN_MAX`以内へ収める責任を負う。

`M_STD_MEASURED <= M_DESIGN_MAX`であっても、それだけで走行・停止・傾斜・電源・熱・耐久を合格としない。性能・品質・検証基本設計の各評価を満たして初めて標準構成を成立扱いとする。

## 4. 利用者の外部搭載物

### 4.1 初期製品方針

初期製品では次とする。

```text
PAYLOAD_USER_MAX = 0 kg
```

これはTank_Robot自身の標準部品を搭載できないという意味ではない。標準バッテリー、基板、砲塔・砲身、サーボ、外装等は標準構成であり、`M_STD_MEASURED`へ含める。

`PAYLOAD_USER_MAX=0 kg`は、利用者が任意の荷物や機器を追加した状態を、Tank_Robotとして走行性能、停止性能、安全性、電気安全、熱性能または耐久性の保証対象にしないことを意味する。

### 4.2 非対応とする例

次は初期製品の通常使用保証へ含めない。

- 荷物を車体上へ載せて運搬する。
- 市販カメラ、スマートフォン、別バッテリー等を利用者判断で追加する。
- 未評価のセンサ、基板、機構部品を取り付ける。
- 標準構成の外装・機構を変更して重量や重心を変える。

これらを物理的に禁止することまでは要求しないが、未評価構成で標準構成と同じ性能・安全性を保証しない。

## 5. 教材としての承認済み追加モジュール

### 5.1 位置付け

将来の教材でセンサ、カメラ、追加基板等を取り付ける場合、利用者の任意の追加搭載物として扱わず、**承認済み追加モジュール構成**として個別に定義する。

承認済み構成は、少なくとも次を固定する。

- モジュール識別子および対象ハードウェアの版。
- 追加質量および取付位置。
- 電源・通信・配線条件。
- 可動部・安全可動範囲への影響。
- 総質量と重心。
- 必要な走行・停止・傾斜・転倒・電源・熱・耐久の再評価範囲。

### 5.2 質量制約

承認済み追加モジュール構成も原則として次を満たす。

```text
M_CONFIG_MEASURED[c] <= M_DESIGN_MAX
```

4.0 kgを超える構成を教材として正式採用する場合は、本書の設計上限自体を見直す基本設計変更とし、追加モジュール評価だけで例外化しない。

## 6. 重心設計範囲

### 6.1 基本原則

`CG_DESIGN_ENVELOPE`は、完成後に座標値を測ってから初めて決めるものではなく、詳細設計が満たすべき安定性条件として先に固定する。

Tank_Robotの支持領域は、左右キャタピラの実接地領域から定義する。詳細なmm座標は機構詳細設計で算出してよいが、次の安定条件自体は変更しない。

### 6.2 水平姿勢で確保する転倒境界までの余裕

標準構成および承認済み追加モジュール構成では、水平な標準路面上で、砲塔・砲身を砲塔・砲身制御の安全可動範囲内の任意位置へ動かした場合でも、重心の鉛直投影が支持領域内に存在すること。

さらに、前後・左右の各転倒境界に対して、支持領域寸法の**10 %以上の静的な余裕**を確保することを初期設計条件とする。

ここで10 %の余裕は、前後方向は有効接地長、左右方向は左右接地外縁間距離を基準に各転倒境界から内側へ確保する。

### 6.3 5°傾斜および可動部姿勢

性能・品質・検証基本設計の初期傾斜評価条件である5°について、前後・左右の代表傾斜方向および砲塔・砲身の安全可動範囲内の不利な姿勢を組み合わせても、重心投影が支持領域外へ出ず、接地を失って静的転倒へ移行しないことを設計条件とする。

5°条件で10 %の余裕まで維持することを一律要求しないが、支持境界上を合格とせず、測定・算定不確かさを考慮した転倒境界までの距離に正の余裕を持つこと。

### 6.4 動的成立性

静的`CG_DESIGN_ENVELOPE`内であっても、加速、減速、旋回、停止、砲塔・砲身動作で転倒・浮き上がり・異常なtrack離脱が発生しないことを性能・品質・検証基本設計の実機評価で確認する。

動的評価が不成立の場合、静的重心条件を満たしていることだけで合格とせず、走行制御の出力、加減速、機構配置、質量配分または本書のdesign envelopeを見直す。

## 7. 実測値と最終保証範囲

### 7.1 標準構成

完成標準構成について、少なくとも次を記録する。

- `M_STD_MEASURED`。
- `CG_STD_MEASURED`または同等の安定性算定根拠。
- ハードウェアの版、バッテリー、外装、砲塔・砲身構成。
- 評価時の床面、温度、battery状態等の性能・品質・検証基本設計の共通条件。

### 7.2 承認済み追加モジュール構成

構成`c`ごとに`M_CONFIG_MEASURED[c]`、`CG_CONFIG_MEASURED[c]`および必要な再評価結果を管理する。

一つの承認済み構成の合格を、質量・位置が異なる別のモジュールへ流用しない。

### 7.3 最終保証範囲の更新

評価完了後は、実測値を性能・品質・検証基本設計および必要な関連基本設計へ反映する。

ただし、最終保証範囲は「実測できた最大値」や「シャーシが機械的に載せられた最大重量」ではなく、該当構成について走行、停止、傾斜、転倒、電源、熱、安全、耐久が成立した範囲とする。

## 8. 評価治具・計測物の扱い

試験で一時的に取り付ける反射マーカー、外部センサ、計測治具、配線等は`PAYLOAD_USER_MAX`へ含める製品の搭載物ではない。

ただし、評価結果へ影響する質量または重心変化がある場合は、次のいずれかを行う。

1. 治具質量・位置を記録し、標準構成との差を評価する。
2. 非接触測定等へ変更して影響を除く。
3. 同じ治具条件で対照評価を行い、比較可能性を確保する。

評価治具を取り付けた状態をそのまま標準製品構成の`M_STD_MEASURED`として登録しない。

## 9. 懸案事項一覧における評価確定待ち分類の読み替え

本書の補完対象について、懸案事項一覧 `BD-ISSUE-003`および`BD-EVAL-014`は次のように読み替える。

### 9.1 基本設計確定済み

- `M_DESIGN_MAX = 4.0 kg`。
- `PAYLOAD_USER_MAX = 0 kg`。
- 任意外部搭載物を通常使用として保証しない方針。
- 承認済み追加モジュールだけを個別評価した正式構成として許可する方針。
- `CG_DESIGN_ENVELOPE`の静的安定余裕10 %、5°傾斜時に正の安定余裕を確保する条件、および動的再評価条件。

### 9.2 評価確定待ちとして残すもの

- `M_STD_MEASURED`。
- `CG_STD_MEASURED`。
- 各承認済み追加モジュール構成の`M_CONFIG_MEASURED[c]`／`CG_CONFIG_MEASURED[c]`。
- 実測構成に対する停止、傾斜、転倒、電源、熱、耐久の成立結果。

したがって、`M_DESIGN_MAX`、`PAYLOAD_USER_MAX`、`CG_DESIGN_ENVELOPE`を「完成後に測って初めて決める値」として詳細設計へ先送りしない。

## 10. 詳細設計へ引き継ぐ事項

詳細設計では次を具体化してよい。

- 部品ごとの質量積上げ、部品表に基づく質量の配分。
- 各部品の配置、締結、配線、外装構造。
- 重心座標の具体mm値、計算model、CAD上の算定方法。
- 支持領域の具体寸法。
- 質量・重心測定治具と測定方法。
- 承認済み追加モジュールの具体設計。

ただし、詳細設計だけで4.0 kg上限、任意の追加搭載物非対応、静的安定余裕10 %、5°安定条件を緩和しない。

---

## 11. 完了判定

本書により、本書の補完対象について次を分離した。

- **設計時に先に固定するもの**：質量上限、利用者が追加する搭載物の扱い、重心安定条件。
- **完成後に測るもの**：標準機体・承認済み構成の実測質量と実測重心。
- **実機で成立確認するもの**：走行、停止、傾斜、転倒、電源、熱、耐久。

これにより、詳細設計が「完成後の測定値が出るまで設計限界が分からない」状態を解消し、実測値を理由に設計限界を後追いで決める循環を防止する。
