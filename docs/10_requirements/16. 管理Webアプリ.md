## 16.1 本章の対象
本章では、VPS上で動作し、PCのWebブラウザから利用する管理Webアプリについて、システム管理者・開発者の認証、管理対象デバイスの状態確認、設定データ管理、ログ・診断情報閲覧、ファームウェア管理、OTA更新管理、監査および異常時処理に関するシステム要求を定義する。

管理Webアプリは、システム管理者・開発者が管理・保守のために使用するWebアプリとする。

本仕様では、一名のシステム管理者・開発者が、一つの管理アカウントを使用して運用する。

本仕様では、所有者用VPSアカウントおよび所有者向け管理Web機能を設けない。

管理Webアプリは、主に次の機能を提供する。
- 管理対象デバイスの登録状態および状態情報の確認
- 設定パッケージの登録、変更、配信対象設定および適用結果確認
- ログおよび診断情報の検索・閲覧
- 署名済みファームウェアの登録および確認
- OTA更新対象の設定ならびに更新結果確認
- 管理操作の監査情報確認

本仕様では、管理Webアプリから本体へ直接通信せず、管理WebアプリはVPS上の情報を登録、変更または参照し、本体は「VPS接続・デバイス認証」に従って必要な情報を取得または送信する。

本仕様では、VPSから本体へ汎用的な管理要求を発行する仕組みを使用しない。
設定およびOTAについては、管理WebアプリでVPS上の配信対象情報を変更し、本体が自身のタイミングでVPSへ問い合わせる方式とする。

管理Webアプリが表示する本体状態は、本体からVPSへ最後に送信された情報を基にする。
管理Webアプリは、表示情報が本体のリアルタイム状態であることを前提としない。

管理Webアプリは、本体の走行、砲塔・砲身、通常停止、緊急停止、緊急停止解除または通常終了を遠隔操作する用途には使用しない。

設定パッケージの構成、検証、保存、適用および切戻しは「設定管理」に定める。

ログおよび診断情報の生成、識別、保存およびVPS送信は「ログ・診断」に定める。

ファームウェアの検証、更新開始条件、書込み、更新後起動確認および復旧は「OTA更新」に定める。

利用者認証、認可、秘密情報保護および暗号通信に関する共通方針は「セキュリティ管理」に定める。

## 16.2 管理Webアプリの基本機能
**SYS-WEB-001：**  
管理Webアプリは、認証済みのシステム管理者・開発者に、本仕様で定める管理・保守機能を提供すること。

**SYS-WEB-002：**  
管理Webアプリは、PCのWebブラウザからHTTPSでVPSへ接続して使用できること。

**SYS-WEB-003：**  
管理Webアプリは、本体側で判定する安全状態、操作可否、設定適用可否またはOTA更新開始可否をWebアプリ独自の判定によって変更しないこと。

**SYS-WEB-004：**  
管理Webアプリは、自身のアプリケーションバージョンまたはBuildIDをシステム管理者・開発者が確認できること。

## 16.3 システム管理者・開発者の認証
**SYS-WEB-010：**  
管理Webアプリは、一つのシステム管理者・開発者アカウントを管理アカウントとして使用すること。

**SYS-WEB-011：**  
管理Webアプリは、管理機能および管理情報へのアクセスに、システム管理者・開発者アカウントによる認証を要求すること。

**SYS-WEB-012：**  
システム管理者・開発者のパスワードは8文字以上64文字以下とし、少なくとも英字および数字をそれぞれ1文字以上含むこと。

**SYS-WEB-013：**  
システム管理者・開発者のログインでは、パスワードに加えて、認証アプリによる時刻ベースのワンタイムパスワードを使用する二段階認証を行うこと。

**SYS-WEB-014：**  
システム管理者・開発者の認証済みWebセッションは、認証成立から最大24時間とし、最後の有効な利用者操作から2時間操作がない場合は終了すること。

**SYS-WEB-015：**  
管理Webアプリは、ログアウト、セッション有効期限切れまたはアカウント失効後に、当該認証済みセッションを新しい管理要求へ使用できない状態とすること。

**SYS-WEB-016：**  
同一アカウントに対する認証失敗が連続して5回に到達した場合、新しいログイン試行を5分間制限すること。

**SYS-WEB-017：**  
設定配信、ファームウェアの配信可能化、OTA更新対象設定その他のセキュリティまたは本体動作へ影響する管理操作では、実行直前にシステム管理者・開発者の再認証を要求すること。

**SYS-WEB-031：**  
管理Webアプリは、本体から取得した状態情報を表示する場合、本体での発生時刻または発生順序、およびVPSが当該情報を受信した時刻を確認可能とすること。

**SYS-WEB-032：**  
管理Webアプリは、本体から最後に状態情報を受信してから経過した時間を確認できること。

**SYS-WEB-033：**  
管理Webアプリは、最新情報を取得できていない場合、保存済みの過去情報を表示していることを識別可能とすること。

**SYS-WEB-034：**  
管理Webアプリは、Wi-FiまたはVPSとの通信状態と、本体のBLE基本操作の可否または安全機能の状態とを区別して表示すること。

## 16.5 デバイス管理および状態確認
**SYS-WEB-040：**  
管理Webアプリは、VPSへ登録されている管理対象デバイスの一覧を表示できること。

**SYS-WEB-041：**  
デバイス一覧では、少なくとも次の情報を確認できること。
- Device ID
- 製品または機種
- ハードウェア構成
- デバイス登録状態
- 現在有効なファームウェアのSemVerまたはBuildID
- 現在有効な設定パッケージのgeneration
- 最終通信時刻
- 現在把握している主要な異常
- OTA更新状態

**SYS-WEB-042：**  
管理Webアプリは、Device IDを使用して対象デバイスを検索できること。

**SYS-WEB-043：**  
システム管理者・開発者は、VPS上にデバイスを登録できること。

**SYS-WEB-044：**  
システム管理者・開発者は、登録済みデバイスを利用停止状態に変更できること。

**SYS-WEB-045：**  
管理Webアプリは、同じDevice IDを持つ複数の有効なデバイス登録を作成しないこと。

**SYS-WEB-046：**  
管理Webアプリは、デバイス証明書について、少なくとも証明書識別情報、有効期間および現在の状態を確認できること。

## 16.6 設定パッケージの管理
**SYS-WEB-060：**  
管理Webアプリは、システム管理者・開発者がVPS上の設定パッケージを参照できること。

**SYS-WEB-061：**  
管理Webアプリは、システム管理者・開発者が設定パッケージに含まれる設定項目および設定値を確認し、変更できること。

**SYS-WEB-062：**  
管理Webアプリは、設定値の入力時に、データ型、必須項目、値域、選択肢および設定項目間の基本的な整合性を確認できること。

**SYS-WEB-063：**  
設定パッケージ内の設定項目を一つ以上変更した場合、管理Webアプリは、現在のgenerationより大きい新しいgenerationを持つ設定パッケージとして登録すること。

**SYS-WEB-064：**  
管理Webアプリは、設定パッケージを配信対象とする前に、対象Device ID、schemaVersionおよび対応ファームウェアとの整合性を確認できること。

**SYS-WEB-065：**  
システム管理者・開発者は、配信可能な設定パッケージの中から、各Device IDの本体に対する配信対象の設定パッケージを指定できること。

**SYS-WEB-066：**  
管理Webアプリは、対象デバイスについて、現在VPS上で配信対象となっている設定パッケージのgenerationと、本体から最後に報告された現在有効な設定パッケージのgenerationを区別して表示できること。

**SYS-WEB-067：**  
管理Webアプリは、本体から報告された設定取得、検証、適用または切戻し結果を確認できること。

## 16.7 ログおよび診断情報
**SYS-WEB-080：**  
管理Webアプリは、本体からVPSへ送信されたイベントログを検索および閲覧できること。

**SYS-WEB-081：**  
管理Webアプリは、イベントログを、少なくとも次の条件を指定して検索できること。
- Device ID
- 期間
- ログ種別
- 重要度
- 発生元機能
- イベント識別子

**SYS-WEB-082：**  
管理Webアプリは、現在発生中としてVPSが把握している異常と、過去の異常イベントを区別して確認できること。

**SYS-WEB-083：**  
管理Webアプリは、対象デバイスから最後にVPSへ送信された主要な診断情報を確認できること。

**SYS-WEB-084：**  
ログまたは診断情報の一部が欠損または破損している場合、その情報が完全ではないことを識別可能とすること。

## 16.8 ファームウェアの登録および管理
**SYS-WEB-090：**  
管理Webアプリは、システム管理者・開発者が署名済みの本体アプリケーションファームウェアをVPSへ登録できること。

**SYS-WEB-091：**  
管理Webアプリは、登録する本体アプリケーションファームウェアについて、「OTA更新」に定めるファームウェア識別情報、バージョン情報、対象情報、完全性確認情報および互換性情報を登録および確認できること。

**SYS-WEB-092：**  
システムは、登録されたファームウェアを配信可能とする前に、登録されたファームウェアと管理情報との整合性を確認し、「セキュリティ管理」に定める方式によって署名および完全性を検証すること。

**SYS-WEB-093：**  
検証に成功したファームウェアだけをOTA更新の配信対象として選択可能とすること。

**SYS-WEB-094：**  
登録済みファームウェアの内容を変更する場合、新しいファームウェア識別子、SemVerまたはBuildIDを持つ別のファームウェアとして登録すること。

## 16.9 OTA更新管理
**SYS-WEB-100：**  
システム管理者・開発者は、配信可能なファームウェアの中から、各Device IDの本体に対するOTA更新対象のファームウェアを指定できること。

**SYS-WEB-101：**  
管理Webアプリは、OTA更新対象を設定する前に、対象デバイスとファームウェアの対象製品、ハードウェア構成、現在把握しているファームウェアおよび互換性情報を確認できること。

**SYS-WEB-102：**  
OTA更新対象として設定されたファームウェアは、本体がVPSへ更新情報を問い合わせた場合に、自機向けの更新候補として取得可能となること。

**SYS-WEB-103：**  
管理Webアプリは、OTA更新対象として設定したことと、本体が更新情報を取得したことと、本体でOTA更新が完了したことを区別して表示すること。

**SYS-WEB-104：**  
管理Webアプリは、OTA更新について、少なくとも次の情報を確認できること。
- 更新対象Device ID
- 更新前SemVerおよびBuildID
- 更新対象SemVerおよびBuildID
- 更新状態
- 更新結果
- 失敗した場合の失敗段階または理由
- 復旧の有無および復旧結果
- 最終更新時刻

- OTA更新対象の設定
- システム管理者・開発者アカウントまたは二段階認証設定の変更

**SYS-WEB-111：**

- 監査識別子
- 操作または事象の種類
- 操作者
- 対象
- 処理結果
- 発生時刻

**SYS-WEB-112：**  
管理Webアプリは、監査情報を検索および閲覧できること。

**SYS-WEB-113：**  
監査情報は、通常の管理Web画面から内容を編集できないこと。

**SYS-WEB-114：**

**SYS-WEB-115：**  
管理Webアプリは、利用者入力、API入力およびアップロードファイルについて、形式、長さ、容量および許可された値を確認すること。

**SYS-WEB-116：**

**SYS-WEB-117：**  
管理Webアプリは、ログアウト後に、ブラウザ履歴またはキャッシュを使用して保護対象情報を認証なしで再表示できないようにすること。

## 16.11 異常時処理
**SYS-WEB-130：**  
管理Webアプリは、VPSとの通信失敗、認証失敗、入力エラー、処理失敗および対象データ取得失敗を区別して表示できること。

**SYS-WEB-131：**  
管理操作の処理結果を確認できない場合、管理Webアプリは当該操作を成功または失敗と推測せず、結果確認できない状態として表示すること。

**SYS-WEB-132：**  
表示している状態情報、ログまたは診断情報の更新に失敗した場合、管理Webアプリは表示中の情報が最新ではない可能性を識別可能とすること。

**SYS-WEB-133：**  
管理WebアプリまたはVPSの再起動後も、確定済みのデバイス情報、設定パッケージ、ファームウェア、OTA更新対象、処理結果および監査情報を復元できること。
